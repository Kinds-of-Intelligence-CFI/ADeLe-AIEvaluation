# Visual processing

This rubric assesses the level of cognitive demands associated with visual processing: recovering the information a task needs from a visual signal, in cases where the signal does not simply present it. The demand is set by how far the required information sits from a direct readout — shown plainly, interleaved with a background, partly destroyed, spread across views none of which suffices, or reachable only by reasoning backwards through how the image was formed. The level of cognitive demands progresses from tasks carrying no visual signal at all to those in which the content is not present in the image in any form and can be recovered only from a model of how the image came about. Where a task shows features of more than one level, the demand is set by the highest it genuinely requires.

Distinguishing visual processing from neighbouring dimensions. This dimension scores getting the content out of the signal, not what is done with it afterwards. Locating a target among distractors is assessed by Attention and Scan (AS), which owns clutter-search; what the recovered content means is assessed by the knowledge dimensions, by Conceptualisation, Learning and Abstraction (CL) and by Mind Modelling (MS); rotating, projecting or otherwise transforming a shape that is already legible is Spatio-physical Reasoning (SNs); and how long perception must be sustained is Volume (VO). Producing images is not perception and is scored nowhere here. A scene containing a great many elements, all of them clear, carries no demand on this dimension.

Level 0: None. The task carries no visual signal, or any image it carries is incidental and nothing the task needs is read from it.
