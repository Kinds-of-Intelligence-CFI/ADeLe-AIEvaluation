# gamearena-plms

Planning (PLp, PLe, PLs) and social (MSm, MSc) labels on the 24 Kaggle Game Arena game × role instances: their demand
profiles, and a model-level test of whether a model's edge on social games matches its EQ-Bench 4 rating. See
`PREREGISTRATION.md`. Data and sources: `../gamearena-data/` (`NOTES.md`). Labels via `adele mass` (spec
`../mass-annotation/specs/gamearena-plms.toml`). Analysis: `analysis/analyse.py` → `results/analysis.json`. Log:
`RUNLOG.md`.
