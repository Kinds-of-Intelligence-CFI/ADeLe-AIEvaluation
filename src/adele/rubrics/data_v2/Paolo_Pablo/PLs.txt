# Situational and environmental understanding
#! ADeLe v2 (agentic) — DRAFT v9, unvalidated | source: Paolo_Pablo | rewritten: 2026-07-30 | driver: how hard it is to find out what is going on

This rubric assesses the level of cognitive demands associated with situational and environmental understanding: establishing the task-relevant state of the world. The demand is set by one question: how hard is it to find out what is going on? The scale ranges from tasks that state everything they depend on to tasks whose state cannot be found out in time and must be predicted. What raises the demand is the work standing between the solver and the fact: whether the fact is supplied, returned by an observation, obtainable only by making the system reveal it, contested between rival explanations, moving while it is established, or out of reach altogether. A changing world is not by itself demanding. As long as looking again returns the current state, the task is easy, no matter how fast the world changes. Change raises the demand only when it outruns checking or inferring key facts.

This dimension covers how the facts come to be known, not what is done with them. Deducing what known facts imply is reasoning or Planning (PLp), and so is combining several looked-up facts into an answer and working out how much remains to be done once a fact is known. Monitoring one's own work is Action Control and Execution (PLe): there the object is the task's own execution, here it is the world. Hidden state that is another agent's beliefs or intentions is Mind Modelling (MSm), and a party's unwillingness to say what they know is Communication and Social Interaction (MSc). Retaining what was observed belongs to the memory dimensions, and knowledge that could be retrieved outside the task to the knowledge dimensions. How much there is to establish, and the time spent observing, are Volume (VO). Sustained vigilance is Attention and Scan (AS).

Level 0: None. The task requires no situational understanding. Everything it depends on is supplied: stated or shown at the outset, or delivered as input in a specified format.
Examples:
* Solve a Sudoku from a printed grid. (The whole state is given; filling the grid is deduction.)
* Find the winning plan in a chess position shown on the board.
* Solve a programming-contest problem whose inputs arrive on stdin in the format the statement specifies.

Level 1: Very low. Tasks at this level require the state to be read: an observation returns the fact — looking at it, asking for it, querying a system, or taking a measurement. A task stays at this level however many facts must be established, and however much searching it takes to reach the place that holds each one.
Examples:
* Check a museum's opening hours before planning a visit.
* Compare fifty products on price and delivery time, each listed on its own catalogue page. (Fifty easy looks; how much there is to establish is Volume.)
* Establish where in an unfamiliar codebase a behaviour is implemented: every file is readable, so however long the search takes, looking returns it.
* Update a customer's address using the one recorded on the recent order they point you to. (Their unwillingness to state it themselves is Communication and Social Interaction.)

Level 2: Low. Tasks at this level require the state to be elicited: no observation states the fact, so the system must be made to produce evidence — run it, probe it, perturb it — and the fact inferred from how it responds. Each candidate explanation has its own decisive test, so they can be run down one at a time, and a conclusion, once established, holds.
Examples:
* Locate a fault in a circuit with a multimeter, each suspect segment testable on its own.
* Debug a failure in code you did not write, where reproducing it shows only the symptom, so each suspected cause must be isolated before the step that produces it is exposed.
* Work out why a houseplant is dying from its appearance and conditions.

Level 3: Intermediate. Tasks at this level require the state to be inferred against rival explanations: the evidence fits several accounts at once and no ready test settles any of them, so observations that discriminate between the accounts must themselves be worked out before anything can be ruled in or out.
Examples:
* Locate a fault that appears only when several subsystems interact, so that every single-component test comes back clean.
* Diagnose a patient whose symptoms are consistent with several conditions at once, none of which a single test excludes.
* Establish why a machine intermittently produces out-of-tolerance parts when the same settings mostly produce good ones.

Level 4: High. Tasks at this level require the state to be established while it moves: the situation changes as it is investigated, so conclusions go stale while they are being formed and the picture must be rebuilt as fast as it is assembled.
Examples:
* Diagnose a production incident while traffic shifts and services degrade under investigation, so that measurements taken minutes apart describe different systems.
* Assess the state of a contested field situation from reports that are partial, aging and mutually inconsistent.
* Track an unfolding outbreak whose case data lags the spread it is meant to describe.

Level 5: Very high. Tasks at this level require the state to be projected without recourse. No observation can reach the state at the moment it must be used: access is severed, the change is unsignalled, the evidence arrives too late, or looking disturbs the thing being looked at. The state must be carried forward from a model of how the situation evolves, and the model itself cannot be checked before it is relied on; where a reliable model is supplied, projecting with it is routine and belongs lower.
Examples:
* Diagnose a race condition whose timing cannot be instrumented without changing it, so what happened must be argued from a model of the interleaving.
* Navigate by dead reckoning in fog where the currents themselves are uncertain, so position must be projected from a model that only landfall can check.
* Fight a building fire that spreads unseen behind walls, revealing itself only intermittently and after the fact.
