# Situational and environmental understanding
#! ADeLe v2 (agentic) — DRAFT v3, unvalidated | source: Paolo_Pablo | rewritten: 2026-07-29 | driver: how hard it is to find out what is going on
 
This rubric assesses the level of cognitive demands associated with situational and environmental understanding: establishing the task-relevant state of the world. The demand is set by one question: how hard is it to find out what is going on? The scale ranges from tasks that state everything they depend on to tasks whose state cannot be found out in time and must be predicted. A changing world is not by itself demanding. As long as looking again returns the current state, the task is easy, no matter how fast the world changes. Change raises the demand only when it outruns checking or inferring key facts.
 
This dimension covers how the facts come to be known, not what is done with them. Deducing what known facts imply is reasoning or Planning (PLp). Monitoring one's own work is Action Control and Execution (PLe): there the object is the task's own execution, here it is the world. Hidden state that is another agent's beliefs or intentions is Mind Modelling (MSm). Retaining what was observed belongs to the memory dimensions, and knowledge that could be retrieved outside the task to the knowledge dimensions. The amount of state, and the time spent observing, are Volume (VO). Sustained vigilance is Attention and Scan (AS).
 
Level 0: None. The task requires no situational understanding. Everything it depends on is supplied: stated or shown at the outset.
Examples:
* Solve a Sudoku from a printed grid. (The whole state is given; filling the grid is deduction.)
* Find the winning plan in a chess position shown on the board.
* Answer a word problem that states every quantity it needs.
 
Level 1: Very low. Tasks at this level require the state to be read. One or a few facts must be established, and a single look, query or measurement returns each one. Once established, a fact holds for the rest of the task.
Examples:
* Check a museum's opening hours before planning a visit.
* Read the current contents of a file before editing it.
* Measure a room before ordering a carpet for it.
 
Level 2: Low. Tasks at this level require the state to be gathered. Many facts must be assembled from several places, and each is returned by a direct look once you look in the right place. A task stays at this level however many observations it takes, and however often the world changes, so long as looking again returns the current fact.
Examples:
* Explore an unfamiliar codebase to establish where a behaviour is implemented, each file directly readable.
* Look up a customer's account, orders and payment methods across several systems before making a change.
* Drive through dense city traffic, where everything task-relevant is visible as it happens. (Sustained vigilance is Attention and Scan; other drivers' intentions are Mind Modelling.)
 
Level 3: Intermediate. Tasks at this level require the state to be inferred by test. Some key piece of data must be worked out from indirect evidence. However, each candidate explanation has a decisive probe, so hypotheses can be run down one at a time. A conclusion, once established, holds.
Examples:
* Locate a fault in an electrical circuit with a multimeter, each suspect segment testable on its own.
* Work out why a houseplant is dying from its appearance and conditions.
* Debug why a program you did not write crashes, where each suspected cause can be switched off or reproduced in isolation.
 
Level 4: High. Tasks at this level require the state to be inferred against entanglement. The evidence fits several explanations at once, or the candidate causes interact, so no ready probe settles any single hypothesis. Observations that discriminate between the rival accounts must be devised. Conclusions may change while they are being formed, because the situation shifts as it is investigated. Critically, what places a task here is that inspection and one-at-a-time testing are not enough.
Examples:
* Diagnose a production incident while traffic shifts and services degrade under investigation, so that measurements taken minutes apart describe different systems.
* Locate a fault that only appears when several subsystems interact, so that any single-component test comes back clean.
* Assess the state of a contested field situation from reports that are partial, aging and mutually inconsistent.
 
Level 5: Very high. Tasks at this level require the state to be projected without recourse. No observation can reach the state at the moment it must be used: access is severed, the change is unsignalled, or the evidence arrives too late. The state must be carried forward from a model of how the situation evolves, and the model itself cannot be checked before it is relied on. Critically, projection from a supplied and reliable model is routine and belongs lower. What places a task here is committing to a picture of the world that nothing available in time can confirm.
Examples:
* Diagnose a race condition that appears and disappears under timing conditions that cannot be observed directly.
* Navigate by dead reckoning in fog where the currents themselves are uncertain, so position must be projected from a model that only landfall can check.
* Fight a building fire that spreads unseen behind walls, revealing itself only intermittently and after the fact.
